# 🫠 밍기적 숫자야구 ⚾️

### 한 줄 소개
숫자야구를 즐길 수 있는 페이지 구현 (BackEnd 로직)  
[⚾️ 밍기적 숫자야구 하러가기](https://nbb/mingizeok.com)

### 프로젝트 배경 & 목표
- Python으로 숫자야구 게임 로직을 만들다 API 개발까지 연결.
- 유저들은 숫자야구 게임 진행 후 랭킹 시스템에 자신의 기록을 저장할 수 있다.
---

### 핵심 기능
- 기능 1: 숫자야구 게임 (세션 기반으로 진행)
- 기능 2: 랭킹 시스템 (구현 전)

---

### 기술 스택
- Python / FastAPI
- Frontend: HTML, CSS, JS -> [👩🏻‍💻 프론트 레포지토리](https://github.com/mingizeok-labs/NBB_front)
- DB: PostgreSQL (사용 예정)
- 기타: Poetry, Pydantic , ...
